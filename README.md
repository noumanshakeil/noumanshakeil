## Who I am

I design and ship **AI systems you can actually run** — hybrid mobile/desktop assistants, retrieval pipelines, multi-agent workflows, and perception stacks. My work sits at the intersection of:

- **Product AI** — PocketMind, receptionists, outreach, news intelligence
- **Agentic & RAG** — tool-calling agents, hybrid retrieval, citations, memory
- **Vision & ML** — detection, recognition, medical imaging, classical ML pipelines
- **Local / edge AI** — Ollama-friendly RAG, embeddings servers, TFLite paths

> *"The worst code is often left public."* — so I leave the good parts public too: architecture, READMEs, and runnable MVPs.
